# Green LCD Theme for Obsidian Publish

## Overview

This is an amalgamation of different themes to make something that resembles simple LCD screens. 
It was inspired by some of the UIs designed in [Mobius Front '83](https://store.steampowered.com/app/971160/Mbius_Front_83/).

## Fonts

The fonts are doing quite a bit of the work here, and I think they look excellent in this theme context. I've always been a fan of retro/pixel fonts. 
The header font is Sysfont, while the body text is using WIN95FA.

See [this blog post](https://starcatgames.ltd/website-theme-updates-march-26) for more details.
