# Green LCD Theme for Obsidian Publish

This is an amalgamation of different themes to make something that resembles simple LCD screens. 
It was inspired by some of the UIs designed in [Mobius Front '83](https://store.steampowered.com/app/971160/Mbius_Front_83/).
